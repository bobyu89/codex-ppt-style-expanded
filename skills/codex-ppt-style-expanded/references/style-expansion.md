# 風格拓展與樣張規格

## 檢索來源

1. `styles.json`：本衍生版的簡報配方；每筆包含 audience、palette、material、layout、template_id、background_prompt。
2. `upstream-ppt/`：codex-ppt 原始 11 種風格。只讀候選檔案；其中的圖片文字要求不適用可編輯模式。
3. `image2-library.json`：awesome-gpt-image-2 的原始結構化索引，保留模板 ID、類別、標籤、案例編號與限制。
4. `image2-templates.md`：上游提示詞正文。依所選模板的 anchor 搜尋對應章節，不必全部讀取。

`search_styles.py --show ID` 顯示配方或模板全文。`--list` 列出全部；上游 PPT 用 `ppt:檔名` 作 ID。上游索引的 cover 是網站路徑，並非本套件內的圖檔；不宣稱已包含案例圖片。要參考案例，開啟來源連結並實際檢視圖片，不根據名稱猜測構圖。

## 從圖像模板轉成簡報風格

匹配順序：用途/受眾 → 簡報資訊密度 → 視覺材質/標籤 → 上游模板及案例。
海報、商品頁或資訊圖不能原封不動當簡報背景：移除其中的文案、數據、Logo、座標軸、圖例與标签要求；只保留適合的質感、構圖與視覺元素。

每次建立風格包至少定義：
- 3–5 個 HEX 色彩；背景、文字、強調色角色。
- 可在目標環境使用的標題/內文字體，繁中缺字時的替代字體。
- 標題/正文/註解字級及頁邊距；投影先以 32–40 / 22–28 / 14–16 pt 規劃，再按實際內容調整。
- 封面、左右內容、比較、流程、資料、結論的版型變體。
- 背景主體位置與留白矩形，預期字數與圖像密度。
- 禁用元素、來源 template_id、案例來源 URL，以及哪些是本次新增設計。

## 共用版型座標

使用 0–1 正規化座標，以下是起點而非固定母片：
- 封面：標題 [0.07,0.22,0.54,0.30]，主視覺右側。
- 左文右圖：標題 [0.06,0.06,0.88,0.12]，內文 [0.06,0.25,0.52,0.60]，圖像 [0.65,0.23,0.30,0.65]。
- 比較：左欄 [0.06,0.26,0.40,0.58]，右欄 [0.54,0.26,0.40,0.58]；裝飾退到邊緣。
- 流程：內容 [0.06,0.30,0.88,0.48]，節點與箭頭用原生物件。
- 資料：圖表 [0.06,0.24,0.62,0.62]，結論 [0.73,0.26,0.21,0.50]；圖表底色保持乾淨。
- 結論：核心句 [0.12,0.28,0.76,0.30]，小型視覺放下緣。

文字多時選擇較空的版型、擴充文字區或拆頁，不以不斷縮字解決。保存一份同內容的樣張資料再換 style-id，防止比較時連內容也改了。

## 背景提示詞組裝

主題與受眾 + 素材用途 + 風格配方 + 比例 + 構圖座標 + 材質/光線 + 禁用項目。

範例（左文右圖，繁中衛教）：
「生成 16:9 簡報用無字背景。受眾為一般民眾，主題為認識居家照護。暖白底與低彩度鼠尾草綠，右側 65%–95% 寬度放柔和黏土質感居家照護物件，物件不要暗示特定治療效果。左側 6%–58%、高度 25%–85% 保持均勻淺色留白，顶部 6%–18% 高度亦保留標題區。柔和側光，少量細節。不要文字、字母、數字、浮水印、Logo、圖表或資訊標籤。」

只把背景送進生圖工具；正式文案存入原生文字層。若產出有意外文字或留白失敗，使用生圖工具修改/重生背景。

## 手繪擴充與 Image 2.5

手寫／手繪需求使用 [HW01–HW09 配方](handdraw-styles.md)，也能保留既有原始手繪方向。新增媒材、線條與構圖選項，不把媒材差異壓縮成換色。模型適配使用 [Image 2.5 流程](image25-workflow.md)，保留舊 Image 2 模板作來源資源，不回填舊案例的模型名稱。
